# BOCRA Frontend Refresh

A React + Vite frontend inspired by the original BOCRA colour theme, redesigned for a cleaner consumer-ready experience.

## Run

```bash
npm install
npm run dev
```

## Backend connection

Create a `.env` file in the project root:

```env
VITE_API_BASE_URL=http://localhost:5000/api
```

## Update these next

- `src/config/site.js` for real social links
- `src/api/endpoints.js` for backend endpoints
- `src/components/FloatingChatbot.jsx` if you want live FAQ or conversational backend integration
